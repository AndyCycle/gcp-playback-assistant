# GCP 课件播放助手

适用于 Chrome 和 Edge 的浏览器扩展，用于在国家药品安全专业技术人员培训网按顺序播放指定 GCP 课程。

## 功能

- 按当前课程分组的顺序播放，一次只打开一个课件。
- 自动确认「是否继续学习？」等播放提示。切换标签页或窗口触发暂停时，尝试从原进度续播。
- 自动打开课程评估问卷，逐题选择第一个可选项并提交。遇到文字题时等待手动填写，网站确认评估完成后接续下一门。

## 安装与使用

1. 克隆本仓库，或通过 GitHub 的「Code → Download ZIP」下载并解压。
2. 打开 `chrome://extensions/` 或 `edge://extensions/`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的 `GCP播放助手` 文件夹。
4. 登录并打开 [GCP 课程页](https://www.nmpaied.com/pc/#/person_center/my_class/user_class?show_details_id=161&id=2)。关闭其他课程播放页，选择「必修课」或「选修课」，点击右下角的「开始自动化」。

需要手动暂停视频时，先点「暂停自动化」。更新本地文件后，在扩展管理页点「重新加载」，再刷新课程页。

更多操作见 [使用说明](./GCP播放助手/使用说明.md)。
